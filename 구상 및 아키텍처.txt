프로젝트 : 클래스와 객체의 역할을 구분하고, 객체 간 상호작용을 설계해 데이터 기반 시각화 대시보드 사이트 ( 조건 : 외부 호스트에서 접속 가능한 웹사이트 )

서버 : aws(코드를 직접 짜야됨), firebase(GUI로 코드 연결해서 코드 없이 쉽게 처리 가능) -> oop수업이기 때문에 서버를 프레임으로 만들어진 걸 사용하면 좋지 않을수도... 

백 : 파이썬(fastapi)
프론트 : html, js(chart.js), css, 리플렉스(파이썬 기반 풀스택 프레임워크)
환경 : 리눅스?

메인 데이터 정보 : 도로, 속도, 이동시간
서브 데이터 정보 : 도로의 좌표 / 도로명(도로 권역 코드), 지도상 거리

시각화할 데이터
서울시 지도 (혼잡도 색으로 표현 : 속도 비교) -> 클릭 : 도로명, 현재 속도, 예상 통과 시간, 구간 거리 -> 한번더 클릭 : 날짜별 이동속도 비교
